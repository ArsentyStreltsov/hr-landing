# Техническое задание для Cursor  
## Прототип лендинга платформы для HR-активаций и корпоративных digital-событий

## 1. Задача сайта

Нужно разработать современный одностраничный B2B-лендинг для продажи технологической платформы, на которой крупные компании могут запускать digital-активации для сотрудников.

Это не сервис, в котором HR самостоятельно собирает игры в конструкторе.

Продукт представляет собой **готовую технологическую основу**, которую команда агентства адаптирует под конкретную задачу компании:

- корпоративное событие;
- праздник;
- вовлекающая кампания;
- онбординг;
- обучение;
- внутренний конкурс;
- HR-квест;
- реферальная программа;
- тимбилдинг;
- коммуникация ценностей компании;
- программа признания сотрудников;
- активности для семей и детей сотрудников;
- инклюзивные проекты;
- соревнования между подразделениями;
- онлайн- или гибридное мероприятие.

Внутри одного проекта могут сочетаться:

- мини-игры;
- квизы;
- задания;
- рейтинги;
- достижения;
- баллы;
- награды;
- командные соревнования;
- прямые трансляции;
- интерактив во время эфира;
- пользовательский контент;
- персональные сценарии;
- розыгрыши;
- голосования;
- коммуникационные блоки;
- интеграции с внутренними HR-системами компании.

Платформа может быть запущена:

- как отдельный корпоративный сайт;
- как мобильный web-app;
- внутри Telegram;
- внутри корпоративного портала;
- по SSO;
- через ссылку из HR-системы;
- с интеграцией во внутреннюю инфраструктуру клиента.

Главная идея продукта:

**Не проводить для каждого HR-повода отдельный дорогой офлайн-ивент, а создать digital-пространство, которое позволяет вовлекать тысячи сотрудников одновременно и запускать внутри него разные активности в течение года.**

Важный экономический аргумент:

Офлайн-мероприятие на несколько сотен человек может стоить сопоставимо с созданием digital-платформы, доступной всей компании.

Необходимо показать эту мысль визуально и достаточно смело.

При этом нельзя утверждать конкретную экономию или стоимость без подтверждения.

Если будет согласована цифра около 5 млн ₽, предусмотреть возможность легко включить формулировку вида:

**«Платформа для всей компании — за бюджет одного большого корпоративного мероприятия».**

И дополнительную визуальную пару:

**300 сотрудников на одном мероприятии**

vs.

**10 000+ сотрудников в одной digital-платформе**

Количество сотрудников использовать пока как демонстрационный пример и хранить отдельно в данных.

# 2. Чем этот лендинг должен отличаться от FMCG-лендинга

Не нужно брать предыдущий лендинг чековых промоакций и просто заменять:

«покупатели» → «сотрудники»  
«чеки» → «HR-система».

Это другой продукт и другая логика продажи.

FMCG-лендинг строится вокруг конкретной промомеханики.

HR-лендинг должен строиться вокруг идеи:

### «Одна digital-платформа — десятки поводов вовлекать сотрудников в течение года».

Главные смысловые акценты:

1. Масштаб.
2. Экономика относительно больших офлайн-мероприятий.
3. Возможность одновременно вовлечь сотрудников из разных городов и офисов.
4. Большая библиотека игровых и интерактивных механик.
5. Возможность проводить внутри платформы совершенно разные HR-активации.
6. Интеграция с корпоративными HR-системами.
7. Возможность персонализировать сценарии под конкретного сотрудника.
8. Аналитика участия и вовлечения.
9. Возможность использовать платформу не один раз, а как постоянную инфраструктуру.
10. Полная адаптация под бренд работодателя.

Не делать центральными темами:

- регистрацию;
- чеки;
- промокоды;
- покупки;
- товар;
- SKU;
- антифрод покупок.

# 4. Главная идея позиционирования

Пользователь сайта должен за первые 15–20 секунд понять:

1. У агентства уже есть готовая технологическая основа.
2. На ней можно запускать разные HR-активации.
3. Не нужно разрабатывать каждое мероприятие с нуля.
4. Платформа позволяет вовлекать значительно больше людей, чем обычный офлайн-ивент.
5. Digital не означает «скучный корпоративный портал»: внутри могут быть игры, трансляции, соревнования, призы, активности и полноценный event experience.
6. Решение можно интегрировать с HR-инфраструктурой компании.
7. Команда агентства сама проектирует сценарий, дизайн, механику и интеграции.

Основное сообщение:

**Корпоративные digital-активации на готовой платформе**

Дополнительный вариант:

**Вовлекайте всю компанию, а не только тех, кто поместился на площадке**

Подзаголовок:

**Создаём игровые HR-платформы для корпоративных событий, обучения, онбординга, конкурсов и внутренних коммуникаций — с играми, трансляциями, рейтингами, наградами и интеграциями с системами компании.**

Дополнительная подпись:

**Не начинаем разработку каждого проекта с нуля. Собираем нужный сценарий из готовых технологических модулей, адаптируем дизайн и разрабатываем уникальные функции под задачу.**

**Расскажите, что хотите сделать для сотрудников. Мы предложим сценарий, подходящие механики и оценим проект.**

# Блок 20. FAQ

### У нас уже есть корпоративный портал. Зачем нужна ещё одна платформа?

Платформа не обязательно заменяет существующие HR-сервисы. Она может использоваться как игровой и event-слой поверх существующей инфраструктуры и при технической возможности интегрироваться с ней.

### Можно интегрироваться с нашей HR-системой?

Если система предоставляет API или другие технические механизмы интеграции, можно спроектировать обмен данными. Возможность и объём интеграции оцениваются отдельно.

### Можно использовать корпоративную авторизацию?

Да, для проекта можно предусмотреть SSO или другой сценарий авторизации в зависимости от инфраструктуры клиента.

### Можно сделать уникальную игру?

Да. Можно использовать готовые игровые механики или отдельно разработать уникальную механику под концепцию.

### Можно провести внутри платформы трансляцию?

Да. Платформа может использоваться как digital-среда вокруг трансляции с интерактивами, голосованиями, квизами, рейтингами и другими механиками.

### Платформа работает только для одного мероприятия?

Нет. Архитектуру можно использовать для одного события или развивать как постоянную площадку для разных HR-активаций.

### HR самостоятельно собирает проекты?

Не обязательно. Основная модель — команда агентства получает задачу, предлагает сценарий и собирает решение под клиента.

### Сколько стоит проект?

Стоимость зависит от количества сотрудников, состава механик, дизайна, интеграций, инфраструктуры и необходимых доработок. После обсуждения задачи готовится отдельная оценка.

# 17. Особое требование к первому прототипу

Сейчас задача не в том, чтобы получить финальный дизайн.

Cursor должен сделать **достаточно проработанный clickable prototype**, по которому можно обсуждать:

- позиционирование;
- последовательность блоков;
- количество информации;
- визуальную драматургию;
- необходимость отдельных секций;
- интерактивные идеи.

Поэтому лучше сделать более смелый и насыщенный первый вариант, который затем можно сократить, чем собрать обычный корпоративный лендинг из одинаковых карточек.

Особенно тщательно проработать четыре экрана:

1. Hero.
2. Offline event vs digital platform.
3. Большой интерфейс самой платформы.
4. Integration map.

Именно они должны визуально отличать этот сайт от FMCG-лендинга.
